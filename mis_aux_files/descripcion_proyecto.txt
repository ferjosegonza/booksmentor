Estas tablas contienen los **valores posibles** que se usan como opciones en las tablas principales.

| Campo | Tipo | Descripción |

### 🔹 Tablas Principales (con FK a Catálogos)

---

#### Tabla: `Usuarios`
**Propósito**: Información de los usuarios registrados.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Email` | Texto (único) | Correo electrónico |
| `Nombre` | Texto | Nombre del usuario |
| `Frecuencia_id` | **FK a `Cat_Frecuencias`** | ⭐ Frecuencia preferida |
| `Plan_id` | **FK a `Cat_Planes`** | ⭐ Plan contratado |
| `Hora_envío` | Hora | Hora preferida para recibir emails |
| `Zona_horaria` | Texto | Ej: "America/Argentina/Buenos_Aires" |
| `Fecha_registro` | Fecha | Cuándo se registró |
| `Activo` | Booleano | Si la cuenta está activa |

---

#### Tabla: `Libros`
**Propósito**: Catálogo de libros disponibles.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Título` | Texto | Título del libro |
| `Autor` | Texto | Nombre del autor |
| `Idioma_original_id` | **FK a `Cat_Idiomas`** | ⭐ **Idioma en que fue escrito el libro originalmente** |
| `Año_publicación` | Número | Año de publicación |
| `Cantidad_enseñanzas` | Número | Total de enseñanzas extraídas |
| `Fecha_procesamiento` | Fecha | Cuándo se generó el contenido |
| `Activo` | Booleano | Si está disponible para usuarios |

---

#### Tabla: `Libro_Tags`
**Propósito**: Relación muchos-a-muchos entre libros y tags.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Libro_id` | **FK a `Libros`** | Libro |
| `Tag_id` | **FK a `Cat_Tags`** | Tag |

---

#### Tabla: `Enseñanzas`
**Propósito**: Cada enseñanza individual extraída de un libro.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Libro_id` | **FK a `Libros`** | Libro al que pertenece |
| `Orden` | Número | Orden dentro del libro (1, 2, 3...) |
| `Texto_original` | Texto largo | **Enseñanza en el idioma original del libro** (definido en `Libros.Idioma_original_id`) |
| `Tema` | Texto | Tema específico de esta enseñanza |

---

#### Tabla: `Traducciones`
**Propósito**: Cache de traducciones para reutilizar. Cada registro es una enseñanza traducida a un idioma específico.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Enseñanza_id` | **FK a `Enseñanzas`** | Enseñanza traducida |
| `Idioma_id` | **FK a `Cat_Idiomas`** | ⭐ **Idioma DESTINO de la traducción** |
| `Texto_traducido` | Texto largo | Enseñanza traducida al idioma destino |
| `Fecha_traducción` | Fecha | Cuándo se generó |
| `Veces_usado` | Número | Contador de reuso |
| `Último_uso` | Fecha | Última vez que se usó |

---

#### Tabla: `Suscripciones`
**Propósito**: Relaciona usuarios con libros y su progreso individual.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Usuario_id` | **FK a `Usuarios`** | Usuario suscrito |
| `Libro_id` | **FK a `Libros`** | Libro que está siguiendo |
| `Estado_id` | **FK a `Cat_Estados_Suscripcion`** | ⭐ Estado de la suscripción |
| `Última_enseñanza_enviada` | Número | Orden de la última enviada (0 = ninguna) |
| `Fecha_próximo_envío` | Fecha/Hora | Cuándo enviar la siguiente |
| `Porcentaje_avance` | **Fórmula** | `([Última_enseñanza_enviada] / lookup('Libros', 'Cantidad_enseñanzas')) * 100` |

---

#### Tabla: `Suscripcion_Idiomas`
**Propósito**: Idiomas seleccionados por el usuario para un libro específico (relación muchos-a-muchos).

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Suscripcion_id` | **FK a `Suscripciones`** | Suscripción |
| `Idioma_id` | **FK a `Cat_Idiomas`** | ⭐ Idioma seleccionado por el usuario para este libro |

---

#### Tabla: `Historial_Envíos`
**Propósito**: Auditoría de todos los emails enviados.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Usuario_id` | **FK a `Usuarios`** | Usuario que recibió |
| `Enseñanza_id` | **FK a `Enseñanzas`** | Enseñanza enviada |
| `Idioma_id` | **FK a `Cat_Idiomas`** | ⭐ Idioma en que se envió |
| `Estado_id` | **FK a `Cat_Estados_Envio`** | ⭐ Estado del envío |
| `Fecha_envío` | Fecha/Hora | Cuándo se envió |

---

#### Tabla: `Sugerencias_Usuarios`
**Propósito**: Almacenar feedback, sugerencias y reportes enviados por los usuarios.

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Autonumérico | Clave primaria |
| `Usuario_id` | **FK a `Usuarios`** | Usuario que envía la sugerencia (puede ser NULL si no está registrado) |
| `Email` | Texto | Email del usuario para contacto (obligatorio si no hay Usuario_id) |
| `Tipo_id` | **FK a `Cat_Tipos_Sugerencia`** | ⭐ Tipo de sugerencia |
| `Libro_sugerido` | Texto | Nombre del libro que sugiere (opcional) |
| `Mensaje` | Texto largo | Contenido de la sugerencia o feedback |
| `Adjunto_url` | Texto | URL de archivo adjunto (opcional) |
| `Leído` | Booleano | Si el admin ya lo revisó |
| `Atendido` | Booleano | Si ya se tomó acción |
| `Fecha_envío` | Fecha/Hora | Cuándo se envió |
| `Fecha_respuesta` | Fecha/Hora | Cuándo se respondió (si se hizo) |
| `Respuesta_admin` | Texto largo | Respuesta del administrador (opcional) |

## 🔄 Flujo Lógico para saber el idioma de las enseñanzas

1. **El idioma original de un libro** se almacena en `Libros.Idioma_original_id`
2. **Todas las enseñanzas** de ese libro están en ese idioma original (`Enseñanzas.Texto_original`)
3. **Cuando un usuario pide una enseñanza en otro idioma**:
   - El sistema verifica si existe en `Traducciones` para esa `Enseñanza_id` e `Idioma_id`
   - Si existe → la reutiliza
   - Si no existe → la genera (1 sola vez) y la guarda
4. **En el historial de envíos** se registra en qué idioma se envió cada enseñanza a cada usuario

## ✅ ¿Por qué esta normalización es superior?

| Problema con el diseño anterior | Solución con esta estructura |
|--------------------------------|------------------------------|
| `Frecuencia` era texto libre | ✅ Ahora es FK a `Cat_Frecuencias` |
| `Plan` era texto libre | ✅ Ahora es FK a `Cat_Planes` |
| `Idiomas` repetidos en múltiples tablas | ✅ Un solo `Cat_Idiomas` referenciado |
| No se sabía en qué idioma estaba el texto original | ✅ `Libros.Idioma_original_id` lo define claramente |
| Tags en texto plano | ✅ Tabla `Cat_Tags` + relación N:N |
| Estados escritos a mano | ✅ Catálogos de estados |
| Dificultad para cambiar un nombre de opción | ✅ Se cambia en UN SOLO lugar |
| Dificultad para saber qué planes existen | ✅ Consulta simple a `Cat_Planes` |

---

## 🚀 Ventajas de esta arquitectura

1. **Mantenibilidad**: Cambias un valor UNA VEZ y se actualiza en todos lados
2. **Escalabilidad**: Agregar un nuevo idioma, plan o frecuencia es INSERT en catálogo
3. **Integridad**: La base de datos garantiza que solo existan valores válidos
4. **Consultas eficientes**: Las FK permiten JOINs rápidos y exactos
5. **Internacionalización**: Los catálogos pueden tener nombres en diferentes idiomas
6. **Claridad**: El idioma de cada texto es siempre explícito (original en libro, destino en traducción)

| Índice | Campos | Propósito |
|--------|--------|-----------|

| `idx_sugerencias_fecha` | `Fecha_envío` | Ordenar por fecha |

## 🔄 Flujo de uso de Sugerencias

```
1. Usuario envía sugerencia
   → Se crea registro en Sugerencias_Usuarios
   → Leído = false, Atendido = false

2. Administrador revisa panel
   → Ve lista de sugerencias pendientes (Leído = false)
   → Lee el mensaje

3. Administrador marca como "Leído"
   → Leído = true

4. Administrador toma acción
   → Si es sugerencia de libro: lo agrega a la cola de procesamiento
   → Si es reporte de error: lo investiga
   → Si es mejora: la evalúa

5. Administrador responde (opcional)
   → Completa Respuesta_admin y Fecha_respuesta
   → Atendido = true
```
